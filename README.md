# TWM World Sandbox

Интерактивный русскоязычный стенд нейросимвольной модели мира TWM v7.10 (Seed 801), предназначенный для развёртывания на Streamlit Community Cloud.

**Состояние публикации: перенос исходников и обученных весов пока не завершён.** Пока в этом репозитории находится только описание проекта. Не выбирайте его для развёртывания Streamlit до появления `sandbox_app.py`, `requirements.txt`, `ui/dist/` и `checkpoints_v*/`.

Архитектурный принцип: модель сама вычисляет `JointConsistencyEnergy` всех допустимых для рассмотрения подмножеств кандидатов и выбирает `argmax`; сервер не фильтрует конфликты и не исправляет полученный результат.

После полной загрузки приложения главная точка входа для Streamlit Cloud: `sandbox_app.py` (Python 3.11).
